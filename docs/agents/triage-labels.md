# Issue 分流标签

工程 skills 使用以下五个固定角色。右侧是本仓库实际使用的 GitHub 标签。

| Skill 角色 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估和分类 |
| `needs-info` | `needs-info` | 等待提出者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可以直接交给 Agent |
| `ready-for-human` | `ready-for-human` | 需要人工判断或实现 |
| `wontfix` | `wontfix` | 已决定不处理 |

当 skill 使用“等待评估”“等待信息”“Agent 可执行”等角色描述时，必须使用本表映射的 GitHub 标签。

`bug`、`enhancement`、`documentation` 等标签描述问题类型；以上五个标签描述问题当前处于什么处理状态，两类标签可以同时使用。
